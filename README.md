# Travel & Holiday Packages Website

Welcome to the Travel & Holiday Packages website! This platform allows users to explore and book travel packages across all continents.

## Features

- 🌍 Browse travel packages by continent (Africa, Antarctica, Asia, Europe, North America, Oceania, South America)
- 📞 Contact form for inquiries and bookings
- 📋 Terms and Conditions page
- 📱 Responsive design for mobile and desktop
- 🎨 Professional and modern UI

## File Structure

```
travel-packages-website/
├── index.html              # Home page
├── styles.css              # Main stylesheet
├── script.js               # JavaScript functionality
├── contact.html            # Contact form page
├── terms.html              # Terms and Conditions page
├── continents/
│   ├── africa.html         # Africa packages
│   ├── antarctica.html     # Antarctica packages
│   ├── asia.html           # Asia packages
│   ├── europe.html         # Europe packages
│   ├── north-america.html  # North America packages
│   ├── oceania.html        # Oceania packages
│   └── south-america.html  # South America packages
├── images/                 # Image folder (create and add images)
└── README.md               # This file
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/casagleam1985/travel-packages-website.git
   ```

2. Open `index.html` in your web browser

3. Customize content in each HTML file as needed

## Customization

- Edit the company name and branding in the header
- Add your actual travel packages in each continent file
- Update the contact form with your email/contact details
- Add images to the `images/` folder and reference them in HTML

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
